# Skill-A-Share-Placement-Discount-Alpha 交接文档

## 一、项目概述

### 1.1 项目背景
本项目为 **A股定增折价解禁Alpha因子**（A-Share Placement Discount Alpha）技能开发，基于定向增发折价率与解禁事件驱动的投资策略。

### 1.2 因子逻辑（v3 最终版）

**核心发现**：实证表明高折价率定增股解禁后表现更差（利益输送+减持动机），低折价率（接近市价）定增股表现更好（参与者看好公司前景）。

**计算公式**：
$$Factor = -Discount\_Rate \times Time\_Weight$$

- **Discount_Rate（折价率）**：`(市价 - 发行价) / 市价`，必须用同日市价计算
- **Time_Weight（时间权重）**：解禁后0-30天权重1.0，解禁前-91~-365天权重0.1
- **方向反转**：因子值取负，使低折价率股票因子值更高→买入信号

**信号逻辑**：因子值越大（折价率越低）→ 买入信号越强，仅基于score排名，不限制折价率

### 1.3 排雷条件
1. 折价率 ≥ 0（排除溢价发行）
2. 必须有解禁日期（inner join，排除无解禁信息的股票）
3. time_weight > 0（聚焦有效窗口内）
4. 排除ST/*ST股票
5. 排除交易状态异常股票

## 四、因子计算流程

### 4.1 流程概览

```
1. 认证登录 → panda_data.init_token(username, password)
2. 获取定增数据 → get_stock_private_placement()（过去3年）
3. 获取限售股解禁数据 → get_restricted_list()（前后各365天）
4. 获取日线行情 → get_stock_daily()（基准日前30天内最新收盘价）
5. 计算折价率 → discount_rate = (市价 - 发行价) / 市价
6. 过滤无效值 → 折价率≥0、市价>0、发行价>0、排除ST
7. 匹配解禁日期 → 按ts_code inner join最早解禁日
8. 计算时间权重 → 距解禁日越近且已解禁权重越高
9. 计算因子值 → factor_value = -discount_rate × time_weight（方向反转）
10. 去重 → 按折价率升序排序，保留最低折价率
11. 生成信号 → buy(score≥80) / hold / sell(score<20)
12. 输出Parquet → 数据库.parquet
```

### 4.2 时间权重函数

| 距解禁日范围 | 权重 | 说明 |
|--------------|------|------|
| 0 ~ 30天（已解禁） | 1.0 | Alpha最强，利空出尽反弹 |
| 31 ~ 60天（已解禁） | 0.7 | 反弹延续 |
| 61 ~ 120天（已解禁） | 0.4 | Alpha衰减 |
| 121 ~ 365天（已解禁） | 0.2 | 远期，低权重 |
| -30 ~ -1天（解禁前） | 0.3 | 承压期，低权重 |
| -31 ~ -90天（解禁前） | 0.2 | 远期，低权重 |
| -91 ~ -365天（解禁前） | 0.1 | 远期，极低权重 |
| 其他 / 无解禁日期 | 0.0 | 排除 |

## 六、使用方法

### 6.1 环境准备
```bash
pip install panda_data pandas numpy pyarrow
```

### 6.2 配置账密
编辑 `.env` 文件：
```
PANDA_USERNAME=your_86_phone_number
PANDA_PASSWORD=your_password
```

### 6.3 运行命令
```bash
cd 开发产物/scripts
python factor.py                                    # 计算因子
python factor.py --as-of-date 20260720              # 指定基准日
python validate.py --base-date 20260601             # 验证因子
python backtest.py --start-date 20250101 --end-date 20260701 --period 20  # 回测
```

## 七、注意事项

1. **认证方式**：必须使用 `panda_data.init_token()`
2. **因子方向**：因子值取负（-discount_rate × time_weight），低折价率→因子值高→买入信号
3. **去重逻辑**：按折价率升序排序，保留最低折价率的定增
4. **signal条件**：仅基于score排名，不限制折价率
5. **数据窗口**：定增数据3年，解禁数据±365天
6. **ICIR**：0.4989接近0.5阈值，可通过扩大样本量进一步优化
7. **账密安全**：运行完成后请清理.env中的账密
